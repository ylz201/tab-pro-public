# Tab Pro

Tab Pro is a free, keyboard-first Chrome and Edge extension for finding, switching and safely cleaning up open tabs. It runs entirely in your browser: no account, no server, no analytics.

Website: https://tabpro.top/

## What Tab Pro Does

- Press `Cmd/Ctrl+Shift+E`, type a few letters, press `Enter` to go to the best match.
- Tabs are grouped by site and project: `Tab` moves between groups, `1`–`9` jumps inside the active one.
- Search by title, URL, domain or project, and filter with `@dupes`, `@stale`, `@pinned`, `@audio`, `domain:` and `window:`.
- Close duplicates while keeping the current, pinned or playing copy. Different Gmail emails are never treated as duplicates.
- Close stale tabs and leftover blank New Tab pages.
- Undo any cleanup, and reopen recently closed tabs.
- Session snapshots, Chrome tab groups, custom grouping rules, import/export.

## Install

Tab Pro is free. The Chrome Web Store and Edge Add-ons listings are in review; install links will appear on https://tabpro.top/#install as soon as they are approved.

## Privacy

Tab data and settings stay in your own browser profile (`chrome.storage.local`). Nothing is sent to the developer or any third party.

Privacy policy: https://tabpro.top/privacy

## FAQ

### Is this the source code repository?

No. This repository is for public product information and support.

### Does Tab Pro replace the new tab page?

No. Tab Pro opens as a popup from the toolbar or its keyboard shortcut.

### Does Tab Pro send my tab data to a server?

No. It uses Chrome's extension APIs and local storage only. An optional Cross-Profile Bridge (off by default) can share tabs between your own Chrome profiles through a program running on your own computer; nothing goes over the internet.
